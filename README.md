# LumiScape: An Interactive Lighting Design Environment for Stage Performance

LumiScape is an interactive lighting design environment for creating and simulating stage lighting performances.

✨ Freely place lighting fixtures
🎨 Edit colors and lighting parameters
⏱ Design timeline-based lighting sequences
🎭 Preview lighting effects in a virtual stage
💡 Connect virtual designs to real lighting systems

Demo: https://muse-studio.github.io/LumiScape/

## Research Project

LumiScape is an academic research project developed by MuseLab, The University of Fukuchiyama.

This repository is publicly available for research dissemination and demonstration purposes. Development is currently conducted within the research group, and external contributions are not accepted at this stage.
